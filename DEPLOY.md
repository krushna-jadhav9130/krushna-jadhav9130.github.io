# Put your portfolio online (free, permanent)

1. On GitHub, create a NEW public repository named exactly:  krushna-jadhav9130.github.io
   (Don't add a README.)
2. Upload this folder's contents to that repo (drag & drop in the GitHub web page,
   or use git: git init, git add ., git commit -m "portfolio", git branch -M main,
   git remote add origin https://github.com/krushna-jadhav9130/krushna-jadhav9130.github.io.git, git push -u origin main).
3. In the repo: Settings -> Pages -> Source: choose "GitHub Actions".
4. Open the "Actions" tab and wait ~1-2 minutes for "Deploy portfolio" to turn green.
5. Your site is live at  https://krushna-jadhav9130.github.io

Every future push to main redeploys automatically.
Tip: when uploading via the web, make sure the hidden .github folder is included.
